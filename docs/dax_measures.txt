REFINERY PROCESS PERFORMANCE & PRODUCTION ANALYTICS
DAX MEASURES

Model tables:
- 'Refinery Data' — cleaned observation-level process dataset
- 'Product Yield Data' — separate unpivoted product-yield table

Create each measure in Power BI using Modeling > New measure.

THROUGHPUT AND FEED
-------------------

Total Throughput =
SUM('Refinery Data'[throughput_bbl])

Total Feed =
SUM('Refinery Data'[feed_volume_bbl])

Throughput Efficiency % =
DIVIDE([Total Throughput], [Total Feed])


ENERGY AND OPERATIONAL RELIABILITY
----------------------------------

Total Downtime Hrs =
SUM('Refinery Data'[downtime_hours])

Downtime Records =
CALCULATE(
    COUNTROWS('Refinery Data'),
    'Refinery Data'[downtime_hours] > 0
)

Total Energy MWh =
SUM('Refinery Data'[energy_MWh])

Energy Intensity MWh per 1000 bbl =
DIVIDE([Total Energy MWh], [Total Throughput] / 1000)

Avg Downtime per Event =
DIVIDE([Total Downtime Hrs], [Downtime Records])


PROCESS CONDITIONS
------------------

Avg Temperature C =
AVERAGE('Refinery Data'[temperature_C])

Avg Pressure bar =
AVERAGE('Refinery Data'[pressure_bar])


PRODUCT YIELD — ORIGINAL WIDE TABLE
-----------------------------------

Avg Gasoline Yield =
AVERAGE('Refinery Data'[gasoline_yield_pct])

Avg Diesel Yield =
AVERAGE('Refinery Data'[diesel_yield_pct])

Avg Kerosene Yield =
AVERAGE('Refinery Data'[kerosene_yield_pct])

Avg Residue Yield =
AVERAGE('Refinery Data'[residue_yield_pct])


PRODUCT YIELD — UNPIVOTED TABLE
------------------------------

Average Product Yield =
AVERAGE('Product Yield Data'[Yield %])


NOTES
-----
- `Downtime Records` counts rows where downtime is greater than zero. It is not a count of distinct or independently verified downtime incidents.
- Check the source percentage scale before formatting yield or efficiency measures as percentages. If values are stored as 35 for 35%, do not apply percentage formatting without first dividing by 100.
- `Avg Downtime per Event` uses the downtime-positive row count as its denominator.
- These measures are for analysis of this synthetic educational dataset.
